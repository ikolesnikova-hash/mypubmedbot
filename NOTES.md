# PubMed-бот: заметки

## Что это
Telegram-бот для нескольких пользователей (отдел, 5 человек). Раз в день ищет
новые статьи в PubMed по темам каждого пользователя и присылает название,
abstract и ссылку. Темы, период и час проверки меняются кнопками (/menu).

## Файлы
- `bot.py` - сам бот (работает постоянно, пока запущен)
- `start_bot.bat` - запуск двойным щелчком (окно не закрывать)
- `.env` - секреты: TG_TOKEN, TG_CHAT (владелец), INVITE_CODE, ANTHROPIC_API_KEY (пока не нужен). Никому не пересылать!
- `users.json` - данные всех пользователей: темы, период, час, какие статьи уже присланы
- `bot_single_user_backup.py` - старая версия для одного человека
- `state.json`, `seen.json`, `topics.txt`, `test_telegram.py` - старые файлы, нужны были только для переноса; можно удалить

## Как подключить коллегу
Коллега открывает бота и отправляет `/start КОД` (код - строка INVITE_CODE в .env).
Без кода бот отвечает "Это закрытый бот". Лимит - 10 тем на человека (MAX_TOPICS в bot.py).
Если код утёк: поменять INVITE_CODE в .env и перезапустить бота (подключённые останутся).
Команда /users у владельца показывает число пользователей.

## Настройки владельца
- Тема: эпигенетические часы метилирования; проверка ежедневно в 12:00, период 2 дня
- Резюме от ИИ нет: приходит оригинальный abstract
